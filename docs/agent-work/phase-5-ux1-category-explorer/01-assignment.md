# Phase 5 UX-1 — Category Explorer

## Objective

Replace the long mixed category-management page with a searchable, status-filtered visual category hierarchy and focused create/edit workspaces.

## Scope

- Preserve the existing category APIs, permissions, readiness rules, publication actions, and archive/restore behavior.
- Show authorized short-lived previews for current or pending category images.
- Give each category a recognizable card with hierarchy, summary, status, and focused actions.
- Move category creation and editing into dedicated static-export-compatible routes.
- Support file selection and drag-and-drop image selection with a local preview before upload.
- Keep keyboard-accessible alternatives and production-safe copy.

## Out of scope

- Record-library redesign.
- Record-editor navigation redesign.
- Record media-gallery redesign.
- Source/evidence redesign.
- Schema changes or public Explore integration.

## Completion gate

A teacher or admin can search and filter the category hierarchy, see available category imagery, open a dedicated create or edit workspace, and retain all existing publication/archive actions. Visitors remain denied by the backend. Existing categories, records, stable IDs, and publication state are unchanged.
