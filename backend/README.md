# Geo-Kurdistan backend

Backend development is intentionally postponed.

The current project phase is a visitor-facing frontend showcase using mock data. Geology teachers and domain experts will review that showcase to validate:

1. Information architecture
2. Content structure
3. Relationships between geological entities
4. Search and category-specific filtering needs
5. Research and document-reading workflows
6. The overall visitor experience

Only after that review should the team finalize the PostgreSQL schema, Prisma models, Node.js/Express API, authentication, authorization, administration tools, payments, premium features, or Geo AI integrations.

No backend application, database migration, API contract, or placeholder production service should be added here during the showcase phase. When backend work is approved, its architecture should be based on validated frontend and content findings rather than assumptions made during prototyping.
